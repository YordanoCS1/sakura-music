# Manual del usuario

Guía de uso de Sakura Music para quien tiene la app instalada o la está
probando por primera vez. Está ordenado como se recorre la app: instalar,
descargar, ordenar, etiquetar, personalizar y, si algo falla, arreglarlo.

## Índice

| Tema | Documento |
|---|---|
| Instalar Python, ffmpeg y abrir la app | [instalacion.md](instalacion.md) |
| Buscar, descargar, playlists, álbumes y la cola | [buscar-y-descargar.md](buscar-y-descargar.md) |
| Escanear, mantener y explorar la biblioteca | [biblioteca.md](biblioteca.md) |
| Editar tags, portadas, lotes, deshacer y letras | [metadatos-y-letras.md](metadatos-y-letras.md) |
| Temas, navegación, densidad, zoom e iconos | [apariencia.md](apariencia.md) |
| Síntomas, causas y diagnóstico | [problemas.md](problemas.md) |

## Ruta sugerida

1. [instalacion.md](instalacion.md) — dejá la app abierta y con ffmpeg listo.
2. [buscar-y-descargar.md](buscar-y-descargar.md) — bajá tu primera canción.
3. [biblioteca.md](biblioteca.md) — elegí una vista y un filtro que te gusten.
4. [metadatos-y-letras.md](metadatos-y-letras.md) — arreglá los tags que vinieron mal.
5. [apariencia.md](apariencia.md) — elegí un tema y, si querés, iconos propios.
6. [problemas.md](problemas.md) — guardalo para cuando algo falle.

## Convenciones del manual

- Los nombres de botones y controles se escriben tal como aparecen en la
  interfaz (**Descargar todo**, **Reintentar errores**, **Aplicar a todo el
  álbum**).
- Las rutas se escriben tal como las ves en Windows
  (`%LOCALAPPDATA%\SakuraMusic\`).
- Los atajos se muestran en código (`` `Ctrl+F` ``).
- Cuando un comportamiento lo garantiza un test, el detalle técnico está en
  [../requisitos.md](../requisitos.md) y el porqué en
  [../adr/README.md](../adr/README.md).
